⚡ QUICK START (3 COMMANDS):

Step 1: Install
   sudo bash install.sh

Step 2: Find your Chromecast
   sudo python3 chromecast_blocker.py discover
   
   → Look for output like: "Found Chromecast devices: 10.42.0.1"
   → Note the IP address

Step 3: Apply Protection (replace 10.42.0.1 with your IP)
   sudo python3 chromecast_blocker.py full-protect --ip 10.42.0.1

✓ You're protected! Continue reading for verification & advanced features.

🎯 WHAT'S PROTECTED:

1. External Access Blocking
   → Prevents remote hackers from controlling Chromecast
   → Only allows local network access
   
2. Eavesdropping Prevention
   → Blocks Google cloud connectivity
   → Stops telemetry and analytics transmission
   → Blocks crash reports and usage data
   
3. DDoS Amplification Prevention
   → Device can't be used in botnet attacks
   → Blocks mDNS, SSDP, and amplification vectors
   
4. MITM Protection
   → Prevents ARP spoofing
   → Validates packet authenticity
   → Drops malformed packets
   
5. Network Isolation
   → Chromecast isolated to local network only
   → No outbound internet access
   → Prevents lateral movement to other devices

⚙️  ADVANCED FEATURES:

For Multiple Devices:
   1. Edit config.yaml with your Chromecast IPs
   2. Run: sudo python3 advanced_blocker.py --config config.yaml protect-all

Continuous Monitoring:
   sudo python3 advanced_blocker.py --config config.yaml monitor

Install as Service (auto-start on boot):
   sudo bash install.sh  # Choose 'y' for systemd installation
   sudo systemctl start chromecast-blocker

Backup Rules:
   sudo python3 advanced_blocker.py --config config.yaml export --output backup.txt
